# Balanced Pattern — لغة الأنماط الخاصة بـ VCG

**Balanced Pattern** هي لغة أنماط (DSL) صغيرة ومدمجة داخل VCG لتصميم واجهات
متوازنة بصرياً: تتقن مقياس تباعد متناظر (balanced spacing scale)، وتدرّجات
لون مُستمدة آلياً من لون أساسي واحد فقط، بدل كتابة CSS يدوياً لكل عنصر.

الفكرة: تُعرّف **رمز اللون الأساسي** ونقطة **وحدة القياس** فقط، وتتولى
Balanced Pattern توليد مقياس تباعد متوازن (xs/sm/md/lg/xl) ومجموعة درجات
لونية متناسقة (سطح، حدود، تمييز، نص خافت) — كل ذلك "متوازن" حول القيم
الأساسية بدل أن تُكتب يدوياً واحدة تلو الأخرى.

## الصياغة

```vcg
pattern Balanced "اسم النمط" {
    unit: 8        # وحدة القياس الأساسية بالبكسل (تُبنى عليها كل المسافات)
    radius: 14     # نصف قطر الزوايا الافتراضي
    primary: "#2f6fed"   # اللون الأساسي (الأزرار، الروابط، التمييز)
    surface: "#0d1320"   # لون الخلفية/السطح
    ink: "#eaf2ff"        # لون النص الأساسي
    muted: "#7f93b3"      # لون النص الخافت
    danger: "#e25b4f"     # لون التحذير/الخطر
}

render "اسم النمط"
```

- **`pattern <Type> "<name>" { ... }`**: يعرّف نمطاً جديداً باسم `name`،
  ويُرجع الاسم نفسه إلى المتغيّر `Type` لتمريره لاحقاً إلى `render`.
  جميع الحقول اختيارية؛ القيم غير المحدَّدة تأخذ قيماً افتراضية متوازنة.
- **`render <Type أو "name">`**: يُولِّد ويُحقن `<style>` تحتوي على كل
  متغيّرات ومقاييس النمط، جاهزة للاستخدام في أي HTML تالٍ عبر `html "..."`.
- **`render <Type> { ... }`**: نفس الشيء، لكنه يفتح كتلة تنفيذ يكون فيها
  المتغيّر `slug` متاحاً (اسم الصنف CSS المُولَّد) لاستخدامه في بناء عناصر
  مخصّصة مرتبطة بهذا النمط تحديداً.

## القيم المُولَّدة آلياً (المتوازنة)

من كل نمط، تُحسب تلقائياً:

| المتغيّر | الوصف |
|---|---|
| `--bp-xs/sm/md/lg/xl` | مقياس تباعد متوازن: `unit×0.5, ×1, ×2, ×3, ×5` |
| `--bp-primary-hover` | تظليل اللون الأساسي بنسبة 12% (للحالة hover) |
| `--bp-primary-soft` | مزج اللون الأساسي مع السطح (لخلفيات الشارات الخفيفة) |
| `--bp-surface-alt` | مزج خفيف بين السطح واللون الأساسي (للبطاقات) |
| `--bp-border` | مزج أقوى بين السطح واللون الأساسي (للحدود) |

## الأصناف الجاهزة (Utility Classes)

كل نمط يُولِّد أصنافاً مُسبَقة الصياغة، مُحاطة تلقائياً باسم النمط لمنع أي
تصادم بين أنماط متعددة في نفس الصفحة:

| الصنف | الاستخدام |
|---|---|
| `bp-section` | حاوية قسم كبيرة بخلفية وحدود وزوايا متوازنة |
| `bp-card` | بطاقة محتوى |
| `bp-grid` | شبكة متجاوبة تلقائياً |
| `bp-row` | صف بفاصل منقّط أسفل العنصر |
| `bp-btn` / `bp-btn bp-ghost` | زر أساسي / زر شبح (بلا تعبئة) |
| `bp-badge` | شارة حالة صغيرة |
| `bp-title` / `bp-muted` | عنوان بارز / نص ثانوي خافت |

## دوال مساعدة عامة

- `tone(hex, percent)` — يُفتّح اللون عند نسبة موجبة، ويُغمّقه عند نسبة سالبة.
  مثال: `tone("#2f6fed", -20)` → درجة أغمق من نفس اللون.
- `mix_color(hex1, hex2, t)` — يمزج بين لونين بنسبة `t` بين 0 و1.

هذه الدوال متاحة في أي مكان بالكود، وليست محصورة بكتلة `pattern`.
