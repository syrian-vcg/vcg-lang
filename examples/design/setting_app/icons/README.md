# مجلد الأيقونات — icons/

ضع هنا أيقونة تطبيقك أو صفحتك بأي من الصيغ التالية:

- `icon.png`
- `icon.jpg` / `icon.jpeg`
- `icon.svg`

ثم اربطها في `setting.app.vcg` عبر:

```vcg
settings.icon("icons/icon.png")
```

يمكنك استخدام أي اسم ملف، فقط تأكد من تطابق المسار الممرَّر لدالة `.icon(...)`
مع اسم الملف الفعلي في هذا المجلد.
